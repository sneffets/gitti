# Security

Please report a security issue privately — not as a public issue — through GitHub's
private vulnerability reporting:
<https://github.com/sneffets/gitti/security/advisories/new>.

Say which app (gitti or gitty) and version you used: Help ▸ About shows it with the git
commit it was built from (Copy Version in gitti, `y` in gitty; `gitti --version`, `gitty --version`).

Fixes go into `main`; there are no maintained older release lines yet.
